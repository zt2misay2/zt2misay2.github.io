2026 年中总结

2026 年中总结

Step in#

​ 似乎还是第一次在 Blog 上写一些不太 CTF，比较生活的东西。

​ 一个暑假浑浑噩噩的过去了，领到的 Agent System Security Work 几乎完全不熟络，大部分时间都停留在和 ChatGPT 的扯皮，无效返工中… 所幸还是出去转了转，看了看 NCC 之外的世界，去见了想见的人，听了听别人的故事。

​ 为什么突然想到要写一篇总结呢，其实现在正在等待 GPT 的相关运行测试结果.. 和小导有关实现，验收标准都有不小的分歧，很大程度上都在无效地返工，很磨人啊… 偶尔从互联网一隅看到其他师傅们的文章，顿感觉自己还是想用文字，在这个地方留下一些自己的印记。

About CTF#

​ 本站建立的最初就是为了分享，记录相关 CTF 做题的记录.. 笔者对于相关计算机专业知识的入手相对缓慢，而对于数学相关知识具备一定的亲和与接纳，自然便在大一下期选择了 Crypto, 虽说那时 Agent 概念还未兴起，但是 LLM 实际上能在相关代码生成方面的部分起到很大的帮助了。

​ 2025 的后续无疑是梦幻的，暑期、秋天的各个比赛几乎全勤，看到比赛就去打，被虐的很开心，新朋友们也很热情，当时维护暑期的练习平台，开学后一起打比赛，XCTF 的日子无疑是开心的，虽说在相关训练，成绩上没有很多的进展，但是当时真的是感觉有一个人，一个 LLM 配合起来就可以快速的学习，上手，解决掉很多难题。面对哪些无法完成的挑战，配合 LLM 也能快速的上手复现，梳理。

​ 但在 2026 开年后，Codex 的出现将自动化解题的最后关卡 — 相关环境与直接上下文的获取完全解决，2025 年末国赛的 Reverse 已经会被 Codex 轻松通杀，而 Crytpo 三道题也没带来过大挑战。再到年初的 LilacCTF 已经对于相关 Agent 尝试做出了对抗，效果勉强；直到 SUCTF ，Crypto 彻底被 Codex 通杀了。

在那之后，很多的线上赛都会被 Agent 队伍彻底撞烂，回看 2025 ，排行榜早就已经是物是人非了。

​ 在相关安全领域，笔者的相关专业知识实在浅薄，也无法从相关宏大的叙事角度展开长篇大论，只是从直观感受来说，传统感觉的 CTF 可能早就不在了，相关的阻塞、思考、试错、求解的正反馈相较于现在有太大区别。作为技术竞赛，它其实不能很贴切的迎合到最先进的安全研究实际了，或者说它需要一个面向 Agent For Security 的转变，阵痛是必然的，但是我也希望能在不远的将来看到更有意思的一种 CTF。

About Life#

Study#

​ 大二的专业课笔者有些应付，以一个勉勉强强的均分结束了我在珞珈山本部最后的时间。

​ 笔者很难清楚自己未来要走什么方向，从无意义盲目的追求读研，到接触了相关校队学长后向往就业赚钱，再到权衡后还是贪图校园的安逸与学生、社团的氛围。笔者不是一个，也无法成为世俗意义上的通吃赢家，很迷茫的跟风处理，去做哪些大家认为都是 “正解” 的东西。有些自愧，我其实没有那种对于技术的痴迷和热爱，我的队友，我的学弟、同伴们，他们拥有的对技术的热忱远超笔者，我也感觉不到我对于 CTF 的那份热爱了，或者说它曾经存在过吧。

​ 但是时间依旧会流逝，人终归会成长，会遗忘；那就姑且撑着自己编织的光鲜的网衣，蜷缩于其下去想象自己所向往的绮丽。未来去哪？未来能去哪？我还不清楚。

Life#

​ 认识了很多朋友，去了一些新的地方。或者说和这些朋友们的聊天是我现在为数不多的心里上的慰藉…
