RSA--e与phi不互素

整理一下e与phi不互素的情况下怎么处理
views | comments

前言#

我们知道，在RSA系统中，解密依赖于欧拉定理

aϕ(p)≡1  mod  p  ,  (a,p)=1a^{\phi(p)}\equiv1\;mod\;p\;,\;(a,p)=1\\aϕ(p)≡1modp,(a,p)=1

以及同余等式

ed≡1  mod  ϕ(n)ed\equiv1\;mod\;\phi(n)\\ed≡1modϕ(n)

,那么在已知

c≡  me  mod  nc\equiv\;m^{e}\;mod\;nc≡memodn

下，容易得到

cd≡  (me)d  mod  nc^{d}\equiv\;(m^{e})^{d}\;mod\;n\\cd≡(me)dmodn ed=1+kϕ(n)ed=1+k\phi(n)\\ed=1+kϕ(n) cd≡  m∗mkϕ(n)  ≡  m∗1  mod  nc^{d}\equiv\;m*m^{k\phi(n)}\;\equiv\;m*1\;mod\;n\\cd≡m∗mkϕ(n)≡m∗1modn

但是当e,phie,phie,phi不互素的情况下，私钥ddd就无法正常计算，在此之下想要顺利求解明文mmm,衍生了一系列问题，本文基于笔者日常中遇到的相关题型，给出对应的处理方法

从简单情况出发#

我们不妨令

gcd(e,ϕ)=tgcd(e,\phi)=t\\gcd(e,ϕ)=t te′=ete^{'}=e\\te′=e

那么考虑转化为公钥指数为e′e^{'}e′的RSA，有

e′d′≡1modϕ(n)e^{'}d^{'}\equiv1mod\phi(n)\\e′d′≡1modϕ(n) c≡  me≡  mte′  mod  nc\equiv\;m^{e}\equiv\;m^{te^{'}}\;mod\;n\\c≡me≡mte′modn cd′≡  mte′d′  ≡  mt  mod  nc^{d^{'}}\equiv\;m^{te^{'}d^{'}}\;\equiv\;m^{t}\;mod\;n\\cd′≡mte′d′≡mtmodn

显然此时我们能够计算

cd′  mod  nc^{d^{'}}\;mod\;n\\cd′modn

如果ttt不是很大（个位数），当mt<nm^{t}<nmt<n的时候，我们直接能得到

cd′  mod  n=mtc^{d^{'}}\;mod\;n=m^{t}\\cd′modn=mt

，直接开ttt次方就能得到mmm

如果mtm^{t}mt不那么大的话，我们姑且还能尝试爆破

cd′=kn+mtc^{d^{'}}=kn+m^{t}\\cd′=kn+mt

，但是如果数据不支持，大到爆破不了，我们就得进一步观察已有数据中的代数结构了

如果eee同时与p−1p-1p−1，q−1q-1q−1互质（CRT加速RSA问题）#

这里也就是在RSA中使用CRT算法加速运算的例子，我们都来讲讲如何操作

为什么要用CRT？

在RSA的计算中，我们有

ed≡1  mod  ϕ(n)ed\equiv1\;mod\;\phi(n)\\ed≡1modϕ(n) c≡  md  modnc\equiv\;m^d\;modn\\c≡mdmodn

，我们知道n=pqn=pqn=pq，nnn往往非常大，那么计算上面两个式子就非常的消耗时间，而且也需要(e,ϕ)=1(e,\phi)=1(e,ϕ)=1,我们注意到p,qp,qp,q也是两个大质数，很有可能eee与即p−1    (ϕ(p))p-1\;\;(\phi(p))p−1(ϕ(p)) ; 即q−1    (ϕ(q))q-1\;\;(\phi(q))q−1(ϕ(q))也互素，那么我能就能把问题转化到模p,qp,qp,q 下来讨论，下面是推导过程

由c≡  me  mod  n由c\equiv\;m^{e}\;mod\;n\\由c≡memodn c≡  me  mod  pc\equiv\;m^e\;mod\;p\\c≡memodp c≡  me  mod  qc\equiv\;m^e\;mod\;q\\c≡memodq

这是由于q∣n  ;p∣nq|n\;;p|nq∣n;p∣n也就是模的传递性，那么我们转过来计算在模p,qp,qp,q下的私钥dp;dqd_p;d_qdp​;dq​，即

edp≡1  mod  ϕ(p)edp\equiv1\;mod\;\phi(p)\\edp≡1modϕ(p) edq≡1  mod  ϕ(q)ed_q\equiv1\;mod\;\phi(q)\\edq​≡1modϕ(q)

那么在解密的时候就有

cdp≡  medp≡  m1+kϕ(p)  ≡  m  mod  pc^{d_p}\equiv\;m^{ed_p}\equiv\;m^{1+k\phi(p)}\;\equiv\;m\;mod\;p\\cdp​≡medp​≡m1+kϕ(p)≡mmodp cdq≡  medq≡  m1+kϕ(q)  ≡  m  mod  qc^{d_q}\equiv\;m^{ed_q}\equiv\;m^{1+k\phi(q)}\;\equiv\;m\;mod\;q\\cdq​≡medq​≡m1+kϕ(q)≡mmodq 记cdp≡  m  mod  p    =m1    cdq≡  m  mod  q    =m2记c^{d_p}\equiv\;m\;mod\;p\;\;=m_1\;\;c^{d_q}\equiv\;m\;mod\;q\;\;=m_2\\记cdp​≡mmodp=m1​cdq​≡mmodq=m2​

这里是因为mmm可能比nnn要大，所以我们无法直接解出来，然后我们根据中国剩余定理可以构造出一个对mmm的解，如下

由第二个同余式不妨设

m=m2+hq  m=m_2+hq\;\\m=m2​+hq

我们进而只需要解出来hhh,把这个式子带入另一个同余式

m2+hq≡  m1mod  pm_2+hq\equiv\;m_1mod\;p\\m2​+hq≡m1​modp hq≡(m1−m2)  mod  phq\equiv(m_1-m_2)\;mod\;p\\hq≡(m1​−m2​)modp

我们只需计算

Iq≡  q−1  mod  pI_q\equiv\;q^{-1}\;mod\;p\\Iq​≡q−1modp

那么有

h≡  Iq(m1−m2)  mod  ph\equiv\;I_q(m_1-m_2)\;mod\;p\\h≡Iq​(m1​−m2​)modp

得到hhh之后回代即可成功求出mmm

可见这里我们的计算都是在模p,qp,qp,q的式子中进行的，乘法运算的次数少了不少，实现了加速

# sage
def AM1M(residue, e, p):
    """
    返回 x^e ≡ residue mod p 的所有解
    """
    if (p-1) % e != 0:
        raise ValueError(f"e={e} 不能整除 p-1={p-1}，AMM 不适用")

    # 分解 p-1 = e^t * s
    t = valuation(p - 1, e)
    s = (p - 1) // (e^t)
    
    # 计算 d = e^{-1} mod s
    d = inverse_mod(e, s)
    
    # 简单情况：t=1
    if t == 1:
        x = power_mod(residue, d, p)
        F = GF(p)
        zeta = F.zeta(e)
        return [ (x * zeta**i) % p for i in range(e) ]
    
    
    # 寻找 e 次非剩余（生成元）
    F = GF(p)
    g = F.multiplicative_generator()
    noresidue = g
    while (noresidue^((p-1)//e)) == 1:
        noresidue *= g
    
    # 计算单位根和辅助变量
    a = power_mod(noresidue, e^(t-1) * s, p)
    b = power_mod(residue, e * d - 1, p)
    c = power_mod(noresidue, s, p)
    h = 1
    
    # Hensel 提升
    for i in range(1, t):
        d_i = power_mod(b, e^(t-1-i), p)
        if d_i == 1:
            j = 0
        else:
            j = -discrete_log(d_i, a)  
        b = (power_mod(c, e, p)^j * b) % p
        h = (power_mod(c, j, p) * h) % p
        c = power_mod(c, e, p)
    
    x0 = (power_mod(residue, d, p) * h) % p
    ω = F.zeta(e)  # e 阶单位根
    return [ (x0 * ω^i) % p for i in range(e) ]  # 返回所有解
